# sgstudy — 结构化学习与概念分析框架

一个基于教育学知识分类和认知心理学的学习辅助框架，帮助你更有深度地理解新概念。

## 核心框架

### 知识四分法（纵轴）

| 类型 | 描述 |
|------|------|
| **事实性知识** | 离散的事实、数据、名称 |
| **结构性知识** | 概念之间的联系、分类、层级 |
| **经验性知识** | 身体经验、情境记忆、实践积累 |
| **元认知知识** | 关于认知的知识、反思能力 |

### 布洛姆分类法（横轴）

```
记忆 → 理解 → 应用 → 分析 → 评价 → 创新
```

### 认知分析矩阵

将知识类型（纵轴）× 认知层次（横轴）组合成 4×6 分析框架，对任意概念进行系统性自我评估。

### Johari Window

四象限分析已知/未知、主体/客体的分布，识别认知盲区。

## 触发场景

- 学习新概念、拆解知识点
- 分析理解深度
- 讨论 AI 认知与人类认知的差异
- 用框架分析知识结构
